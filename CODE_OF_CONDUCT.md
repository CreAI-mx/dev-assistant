# Code of Conduct

This project adopts the **Contributor Covenant, version 2.1** as its code of conduct.

The full text is published at:

- https://www.contributor-covenant.org/version/2/1/code_of_conduct/
- Plain text: https://www.contributor-covenant.org/version/2/1/code_of_conduct/code_of_conduct.txt

By participating in this project — opening issues, submitting pull requests, commenting, or otherwise interacting in project spaces — you agree to abide by its terms.

## Reporting

Concerns about conduct in this project should be reported privately to:

**juangonzalez@creai.mx**

Reports will be reviewed and handled confidentially. While this project is in alpha, response times are best-effort and not guaranteed.

## Scope

This Code of Conduct applies within all project spaces (issues, pull requests, discussions, commit messages) and when an individual is officially representing the project in public spaces.
