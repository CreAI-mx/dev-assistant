# Process objectives (defaults)

These are the standard process objectives applied to all issues in this repo. Customize this file to match your repo's actual conventions — the gather phase loads it at the start of every issue.

- [ ] Follow the repo's git branching strategy (feature branches from main, PR-based merges)
- [ ] Commit messages follow the repo's commit convention
- [ ] All changes go through code review before merging
- [ ] Tests pass before merge (if the repo has tests)
- [ ] Documentation updated when behavior changes
- [ ] No secrets, credentials, or sensitive data committed

Edit, add, or remove items as needed for this repo. Items here become part of every issue's `gathering/objectives.md` under "Process objectives," and later phases will track them as the issue progresses.
